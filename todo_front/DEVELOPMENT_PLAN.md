# План разработки Todo Frontend

## Цель

Создать типобезопасное React-приложение для управления задачами и интегрировать его с REST API, описанным в `http://localhost:5275/swagger/v1/swagger.json`.

## Этапы

- [x] 1. Изучить Swagger-контракт: модели, маршруты, коды ответов и ограничения полей.
- [x] 2. Инициализировать React + TypeScript проект и настроить базовые инструменты качества кода.
- [x] 3. Спроектировать слои приложения: доменные типы, API-клиент, состояние запросов и UI-компоненты.
- [x] 4. Реализовать получение, создание, редактирование, переключение статуса и удаление задач в соответствии с API.
- [x] 5. Реализовать адаптивный и доступный интерфейс, состояния загрузки, пустого списка и ошибок.
- [x] 6. Добавить безопасную конфигурацию URL API через переменные окружения и документацию запуска.
- [x] 7. Проверить сборку, статический анализ и основные пользовательские сценарии; исправить найденные проблемы.

## Архитектурные принципы

- UI не зависит напрямую от формата HTTP-ответов: интеграция изолируется в API-слое.
- Серверное состояние управляется отдельно от локального состояния форм.
- Ошибки сети и неуспешные HTTP-ответы обрабатываются централизованно и показываются пользователю безопасно.
- Все входные данные валидируются до отправки, пользовательский контент выводится без небезопасной HTML-инъекции.
- Компоненты остаются небольшими, переиспользуемыми и типобезопасными.

## Критерии готовности

- Приложение запускается локально документированной командой.
- Все поддерживаемые бэкендом CRUD-операции доступны из интерфейса.
- Интерфейс корректно работает на мобильных и десктопных экранах.
- Ошибки API не ломают страницу и дают понятную возможность повторить действие.
- Production-сборка и проверки качества проходят без ошибок.
