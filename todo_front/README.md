# Точка — Todo frontend

React + TypeScript клиент для TodoList API. Интерфейс поддерживает создание, просмотр, редактирование и удаление проектов и задач, поиск и фильтрацию задач по проектам.

## Запуск

Требования: Node.js 20+, npm и запущенный backend на `http://localhost:5275`.

```bash
npm install
npm run dev
```

Не закрывая терминал с Vite, откройте `http://127.0.0.1:5173`. В development запросы `/api` проксируются на локальный backend.

## Конфигурация API

Скопируйте `.env.example` в `.env.local`, если API расположен не по стандартному адресу. Переменная `VITE_API_BASE_URL` должна содержать базовый путь с `/api`:

```env
VITE_API_BASE_URL=https://api.example.com/api
```

Не помещайте секреты в переменные с префиксом `VITE_`: они доступны в браузере.

## Проверки

```bash
npm run lint
npm run test
npm run build
```

Swagger-контракт не содержит признака завершённости задачи, поэтому UI не хранит фиктивный локальный статус и реализует только поддерживаемые сервером операции.
